# نظام الموجهة الطلابية

نسخة مهيأة للنشر مباشرة على GitHub Pages وللاستخدام على iPhone كتطبيق ويب.

## الرفع إلى GitHub
ارفع جميع محتويات هذا المجلد كما هي إلى المستودع، ثم فعّل GitHub Pages من الفرع `main` والمجلد `/ (root)`.

## على iPhone
افتح رابط GitHub Pages في Safari ثم: مشاركة → إضافة إلى الشاشة الرئيسية.

> البيانات محفوظة محليًا في متصفح الجهاز. احفظ نسخة احتياطية دوريًا من داخل البرنامج.


## تحديثات هذه النسخة
- زر (+) بجانب كل قائمة اختيار لإضافة خيار جديد وحفظه على الجهاز.
- اليوم يتغير تلقائيًا فور تغيير التاريخ، بما في ذلك على iPhone.
- تم تحديث ذاكرة التخزين المؤقت للتطبيق لتجنب بقاء النسخة القديمة بعد رفعها إلى GitHub.
